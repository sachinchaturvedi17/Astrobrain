# TalkingHead Blender files (MIT)

Copied unchanged from https://github.com/met4citizen/TalkingHead (`blender/MPFB/`), MIT licence by Mika Suominen, see `LICENSE-TalkingHead-MIT.txt`.

- `talkinghead-addon.py`: Blender add-on (Edit > Preferences > Add-ons > Install from Disk).
- `talkinghead.mpfbskel`: Mixamo-compatible rig for MPFB.
- `talkinghead.mhw`: bone weights for that rig.

Used to build the NaradVani 3D avatar. See `docs/AVATAR_BUILD_RUNBOOK.md`.
